# Execution Playbook — Foundation

## Activation Friction
Possible tactics:
- shorten onboarding
- default template
- guided first task
- demo result
- reduce required fields
- improve loading / reliability

Use when:
user intent is valid, but value path is too difficult.

Do not use first when:
acquisition quality is the actual problem.

Metrics:
Activation Rate / TTV / Step CVR / Error Rate.

## Habit / Engagement
Possible tactics:
- streak
- check-in
- progress
- challenge
- trigger
- reward

Use when:
core value already exists and repeated use is naturally valuable.

Do not use when:
product is inherently low-frequency or activation is not established.

Metrics:
D7 / D30 / core-action frequency / engagement quality.

## Lifecycle Recall
Possible tactics:
- Push
- Email
- CRM
- win-back
- personalized reminder

Use when:
users previously received value and became inactive.

Do not use when:
users never activated.

## Acquisition Quality
Possible tactics:
- audience refinement
- creative promise alignment
- channel mix
- landing-page prequalification

Judge with:
Channel × Activation × Retention × LTV.

## Monetization Friction
Possible tactics:
- pricing
- packaging
- trial
- paywall
- payment flow

First distinguish:
value problem vs price problem vs timing problem vs payment problem.
