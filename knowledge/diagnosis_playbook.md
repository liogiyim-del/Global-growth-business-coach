# Diagnosis Playbook

## Universal Growth Diagnosis

### 1. Define the Signal（确认异常）
Metric / time / magnitude / market / platform / segment / definition.

### 2. Decompose the Metric（拆指标）
Use mathematical identities before brainstorming causes.

### 3. Segment（切分）
Market / Channel / Cohort / Platform / Version / New vs Existing / User Segment.

### 4. Generate Hypotheses（提出假设）
Prefer 2–4 competing explanations.

### 5. Define Evidence（验证证据）
Ask which table, event, experiment, user research, log, or qualitative evidence can separate hypotheses.

### 6. Prioritize（排优先级）
Impact / confidence / effort / urgency / information value.

### 7. Action & Experiment（动作与验证）
Only after mechanism is sufficiently understood.

## Default Data Request
- rows: time × channel × platform × version
- columns: funnel counts + conversion rates
- filters: target market / cohort
- comparison: baseline / control / previous periods
