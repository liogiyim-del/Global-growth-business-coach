# Global Growth Business Coach V1

This package contains the first validated version of the Global Growth Business Coach.

## What is included

- Skill behavior: `SKILL.md`
- Product requirements: `PRD.md` and `prd.html`
- System behavior: `SYSTEM_PROMPT.md`
- Intent routing: `ROUTER.md`
- Learning engine: `LEARNING_WORKFLOW.md`
- Evaluation: `EVALUATION_RUBRIC.md`
- User state: `USER_STATE_SCHEMA.md`
- 60-day curriculum: `curriculum/60_day_curriculum.json`
- Schemas: `schemas/`
- Foundation knowledge starter: `knowledge/`
- Research policy: `research/SOURCE_POLICY.md`
- HTML lesson template: `templates/lesson_template.html`
- Day 1–7 Gold Standard examples: `examples/`
- Week 1 Transfer Test: `examples/week1_transfer_test.html`

## Recommended use

1. Load / install this Skill package.
2. Start with: `进入 Learning Mode，从 Day 1 开始。`
3. Or use: `Business Mode：帮我分析这个增长问题……`
4. Or use: `Interview Mode：给我一道海外用户增长 Case。`
5. Or use: `Review Mode：复习我当前最弱的三个点。`

## Important

Day 1–7 are examples used to validate output quality.

Day 8–60 should be generated dynamically from the curriculum and state, not manually prewritten.

## V1 status

Prototype-validated architecture.
The next iteration should be based on real usage, Week 1 Transfer Test performance, and repeated failure patterns.
